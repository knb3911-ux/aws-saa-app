# AWS SAA-C03 練習問題

AWS 認定ソリューションアーキテクト – アソシエイト（SAA-C03）のオリジナル練習問題を、スマホで解く個人用 PWA です。
応用情報の過去問アプリ（[ipa-ap-app](https://github.com/knb3911-ux/ipa-ap-app)）と同じ使い勝手にしています。

- 公開先: https://knb3911-ux.github.io/aws-saa-app/ （GitHub Pages）
- 問題は **すべてオリジナル**です。AWS の過去問・ダンプ・他サイトの問題・公式サンプル問題は収録していません
- 試験ガイドの 4 分野・出題比率に合わせています（セキュア 30% / 障害に強い 26% / 高パフォーマンス 24% / コスト最適化 20%）
- 本番と同じシナリオ型。1 つ選ぶ問題（4 択）と、2 つ以上選ぶ問題（5 択以上）があり、全問に日本語の解説（正答の根拠と誤答肢が違う理由）が付きます

## 機能

- ホーム: 解答済み数・正答率・要復習数
- 出題: ランダム／未解答／要復習／ブックマーク／分野別（各 10 問）、セット別の通し
- 模擬試験: 65 問・130 分のタイマー付き。終了まで正誤は出さず、終了後に採点と見直し
- 「わからない」ボタン、答えるとすぐ正誤と解説（複数選択は「回答する」で確定）
- 結果画面、統計画面、オフライン対応（PWA）、ダークモード
- 学習履歴はブラウザの localStorage のみ（端末間の同期なし）

## 開発

```
npm install
npm run dev        # http://localhost:5173/aws-saa-app/
npm test
npm run build
```
